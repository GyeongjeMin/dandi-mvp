# 단디 3D 캐릭터: 모델·애니메이션·대화 연동

## 1. 지금 들어 있는 것

| 항목 | 내용 |
|---|---|
| 모델 파일 | `client/public/models/dandi.glb` (glTF 2.0 바이너리, 약 1MB, 삼각형 약 4.7만 개, 재질 15개) |
| 만드는 방법 | `client/scripts/build-dandi-model.mjs` → `npm run model` (client 폴더) |
| 근거 | 제품 사진(`public/landing/dandi-original.jpg`)의 정면·옆면에 격자를 놓고 머리·얼굴·눈·코·입·몸통·배·팔·조개·발·꼬리 위치와 비율을 재서 만듦. 색도 사진에서 추출 |
| 재질 | 봉제 인형 질감: 거친 표면 + `KHR_materials_sheen`(천 광택). 눈 반짝임만 약하게 발광 |
| 렌더러 | Three.js 0.170 (`client/src/lib/avatar/DandiAvatar.ts`). 대화 화면을 열 때만 불러옴(별도 파일, gzip 약 148KB) |
| 확인 화면 | `#/dandi-3d`: 끌어서 돌리기, 상태·표정 버튼, 움직임 줄이기 (로그인 불필요) |

이 모델은 실제 3D 메시입니다. 어느 방향으로든 돌릴 수 있고, 움직이는 부위는 이름 붙은 노드로 나뉘어 있습니다.

다만 **전문 모델러가 조각(sculpt)한 모델은 아닙니다.** 구·회전체·튜브 같은 기본 형태를 사진 비율에 맞춰 조합했습니다. 털 질감, 바느질선, 손가락 같은 세부는 없고, 실제 인형과는 차이가 있습니다. 대회 시연 이후 품질을 높이려면 아래 4장의 Blender 절차를 권장합니다.

## 2. 노드 구조 (웹 애니메이션이 의존하는 '이름 약속')

```
Dandi                     ← 전체 (끌어서 돌리기, 기쁠 때 통통)
└─ Body                   ← 몸 기울이기
   ├─ BodyMesh, Belly     ← 숨쉬기(세로 크기)
   ├─ FootL, FootR
   ├─ Tail                ← 꼬리 흔들기 (기쁠 때 더 빨리)
   ├─ ArmL, ArmR          ← 어깨가 회전 중심 (숨쉬기·말할 때 손짓)
   ├─ Shell               ← 조개
   └─ Head                ← 목이 회전 중심 (끄덕임·갸웃·두리번)
      ├─ HeadMesh, Face, Brow, Snout, Nose, Whiskers
      ├─ EarL, EarR       ← 들을 때 귀 기울이기
      ├─ EyeL, EyeR       ← 세로 크기로 깜빡임·내리깐 눈, 위치로 시선
      ├─ EyeHappyL/R      ← 웃는 눈(^ ^). 평소엔 세로 0
      ├─ Mouth            ← 'w' 입 선 (기쁠 때 가로로 조금 넓게)
      ├─ MouthOpen        ← 말할 때 벌어지는 입 안 (세로 0~1)
      └─ CheekL, CheekR   ← 볼 홍조 (불투명도)
```

같은 이름으로 만든 다른 GLB(예: Blender에서 다시 만든 모델)를 `public/models/dandi.glb`에 넣으면 웹 코드는 그대로 동작합니다.

## 3. 애니메이션과 대화 연동

### 상태 머신 (`client/src/lib/avatar/machine.ts`)
캐릭터 상태는 **실제 대화 이벤트로만** 바뀝니다. 시간이 지나면 저절로 상태가 바뀌는 타이머는 없습니다.

| 이벤트 | 어디서 오나 | 캐릭터 |
|---|---|---|
| `PHASE: preparing / paused / error / idle` | 음성 대화 진행자(`lib/voice.ts`) | 대기 |
| `PHASE: listening` | 음성 인식 시작 | 듣기: 앞으로 기울이고 갸웃, 귀 기울이기 |
| `HEARD` | 음성 인식이 말을 실시간으로 받아 적을 때마다 | 경청 끄덕임 (1.3초에 최대 한 번) |
| `PHASE: thinking` | 말이 끝나 서버로 보냄 | 생각: 고개를 기울이고 눈을 위로. 표정은 중립으로 |
| `EMOTION` | 서버 스트리밍의 첫 이벤트(`meta`) | 다음 말하기의 표정 예약 |
| `PHASE: speaking` | 첫 문장을 읽기 시작 | 말하기 + 예약된 표정 적용 |
| `SPEECH: start / word / end` | 음성합성의 실제 시작·단어 경계·끝 | 소리가 나는 동안만 입이 움직이고, 단어 경계에서 입을 크게 |

### 늘 흐르는 층 (상태와 무관)
눈 깜빡임(2.4~6초 간격, 가끔 두 번), 호흡(약 3.8초 주기), 대기 중 두리번거림, 꼬리 흔들기.

### 부드러운 전환
모든 값(고개 각도, 눈 크기, 입 벌림, 볼 홍조 등)은 목표값을 지수 감쇠로 따라갑니다. 상태가 바뀌어도 튀지 않고, 입처럼 빠른 값과 자세처럼 느린 값은 따라가는 속도가 다릅니다.

### 표정 고르기 (`server/src/domain/emotion.ts`)
- 어르신 말에 **분명한 표현**이 있을 때만 표정이 바뀝니다. 즐거운 표현(1등, 즐거웠지, 결혼, 축하…)이면 **기쁨**, 힘든 표현(외로워, 돌아가셨어, 아파, 그리워…)이면 **공감·위로**입니다.
- 둘 다 섞이면 공감을 우선하고, 애매하면 **중립**입니다. 감정을 판단하거나 단정하는 기능이 아니라 캐릭터 연기용 규칙입니다.
- 첫 인사, 사진 보기·기억 저장에 "응"이라고 답했을 때, 마무리 인사는 반가운 표정입니다.

### 움직임 줄이기
설정 → 단디와 이야기하는 방식 → '단디 움직임 줄이기'로 켤 수 있고, 계정에 저장됩니다. 기기의 '동작 줄이기' 설정도 따릅니다. 켜면 진폭 35%, 속도 60%로 줄고, 통통 튀는 동작은 꺼집니다.

## 4. 브라우저 제약 (사실대로)
- **입 모양**: 브라우저 음성합성은 소리 데이터(파형)를 웹페이지에 주지 않습니다. 그래서 입 모양은 실제 소리 크기가 아니라 음성합성의 '시작·단어 경계·끝' 신호에 맞춰 움직입니다. 단어 경계 신호는 목소리마다 지원이 다르고, 신호가 없으면 일정한 리듬으로 움직입니다. 음절 단위로 정확히 맞추려면 서버형 음성합성(소리 파일을 받아 Web Audio로 분석)이 필요합니다.
- **3D 미지원 기기**: WebGL을 쓸 수 없는 기기에서는 사진 캐릭터로 자동 대체됩니다.
- **끝 신호 누락 대비**: 크롬은 가끔 '말하기 끝' 신호를 보내지 않습니다. 문장 길이로 계산한 시간이 지나면 다음으로 넘어가는 안전장치를 넣었습니다.

## 5. Blender로 고품질 모델 만들기 (향후 권장 절차)

1. **참고 이미지**: `dandi-original.jpg`의 정면·옆면을 Front/Side 참조 이미지로 놓습니다. 현재 GLB를 File → Import → glTF로 불러오면 비율 기준으로 쓸 수 있습니다.
2. **형태**: 머리·몸통을 Subdivision Surface로 하나의 매끈한 메시로 만들고, 얼굴 크림색 영역과 배는 재질 경계(Material Index)로 나눕니다. 폴리곤은 휴대폰을 고려해 2만~4만 삼각형을 권장합니다.
3. **질감**: Principled BSDF의 Sheen(0.5~1) + Roughness 0.9로 천 느낌을 냅니다. 털 노멀맵은 1K 해상도 1장 정도로 충분합니다.
4. **뼈대(Armature)**: Root → Body → Head(목 회전 중심), ArmL/R(어깨), Tail(2~3마디), EarL/R. 뼈 이름은 2장의 노드 이름과 맞춥니다.
5. **표정(Shape Keys)**: `blink`, `smile_eyes`, `soft_eyes`, `mouth_open`, `mouth_wide`. 웹 코드는 노드 크기 대신 모프 가중치(`morphTargetInfluences`)를 쓰도록 바꾸면 됩니다(`DandiAvatar.animate`의 적용부만 수정).
6. **내보내기**: File → Export → glTF Binary(.glb). Apply Modifiers, +Y Up, Shape Keys·Skinning을 포함합니다. 필요하면 `gltf-transform`으로 Draco·Meshopt 압축을 적용합니다.
7. **교체**: `client/public/models/dandi.glb`를 바꾸고 `#/dandi-3d`에서 상태·표정을 확인합니다.

에셋 권한: 현재 모델은 이 프로젝트에서 직접 만든 것이고 외부 3D 에셋은 쓰지 않았습니다. Three.js(MIT)와 RoomEnvironment(Three.js 예제, MIT)만 사용합니다.
